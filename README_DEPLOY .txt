AVA Dental Lab – نسخة دخول المدير

هذه نسخة أولية مدمجة بملف index.html وتستخدم Supabase Auth لتسجيل دخول المدير فقط.
لا تتضمن هذه النسخة بعد مزامنة بيانات الأطباء والطلبات والحسابات إلى قاعدة البيانات؛ بيانات الواجهة الحالية محلية في المتصفح. لا تستخدمها لإدخال بيانات مرضى أو حسابات حقيقية قبل إكمال ربط الجداول واختبار RLS.

للتشغيل: ارفع index.html إلى استضافة HTTPS. سجّل الدخول ببريد وكلمة مرور مستخدم المدير الذي أنشأته في Supabase Authentication.
